# Number Guessing Game

A simple number guessing game where the user tries to guess a randomly generated number between 1 and 100.

## Key Requirements
- Python
- `random` module

## How to Play
1. Run the `number_guessing_game.py` script.
2. Follow the on-screen instructions to guess the number.
3. Enjoy the game!

## Installation
1. Ensure Python is installed on your system.
2. Clone or download this repository.
3. Run the game using the command: `python number_guessing_game.py`

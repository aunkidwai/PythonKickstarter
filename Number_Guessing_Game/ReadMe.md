# Number Guessing Game

A simple game where the user guesses a random number between 1 and 100. The game provides hints if the guess is too low or too high and tracks the number of attempts.

## How to Run

1. Make sure you have Python installed on your system.
2. Clone or download this repository.
3. Navigate to the project directory.
4. Install the required modules using `pip install -r requirements.txt`.
5. Run the game using `python main.py`.

## Features

- Randomly selects a number between 1 and 100.
- Provides hints if the guess is too low or too high.
- Tracks and displays the number of attempts taken to guess the number.

## Key Requirements

- Python
- `random` module

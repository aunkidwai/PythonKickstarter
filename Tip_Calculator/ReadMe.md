# Tip Calculator

This simple Python project calculates the tip amount based on the total bill and the tip percentage provided by the user. It is a great way to reinforce arithmetic operations and user input handling in Python.

## How to Run

1. Ensure Python is installed on your system.
2. Clone or download the repository.
3. Open a terminal or command prompt.
4. Navigate to the directory containing `tip_calculator.py`.
5. Run the script using the command: `python tip_calculator.py`
6. Follow the prompts to enter the total bill and tip percentage.
7. The program will display the calculated tip amount.

## Requirements
- Python 3.x

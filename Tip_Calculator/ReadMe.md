A simple tip calculator application designed to compute the tip amount and total bill based on user inputs. The program prompts the user to enter the bill amount and the desired tip percentage. It then calculates the tip and the total (bill + tip), displaying both results in a clear format. Key features include:
- Input handling for numerical values and percentage,
- Arithmetic operations to compute tip and total,
- Output formatting for readability,
- Error handling for invalid inputs (e.g., non-numeric values).
This project serves as an introductory exercise in building command-line applications, focusing on user interaction, basic calculations, and result presentation using Python. Optional Tkinter integration can later be added for a graphical interface, but the core implementation remains focused on functionality over complexity.
